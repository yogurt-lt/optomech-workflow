# F35 F2.8 电动内对焦 v0.2：扩缘相抵、后组统一压紧

本版替换后组机械。原 v0.1 保留在相邻文件夹，调焦机构按已确认的方案保留。

## 本次改动

- 取消薄片光阑、两只独立胶接镜框及独立 L7 后镜筒。
- 固定主筒内增加一个后组阶梯孔，一次从后端装入整套后组。
- L3～L6 的新制造机械毛坯外径由 Φ21 增至 Φ22.4。两胶合组在 r10.7～11.2 的环带直接相抵，接触面为原光阑 Z47.922517 mm。
- L4 后侧环带向后增加约0.03708mm，L5 前侧环带向前增加约0.03323mm。接触区完全在原有效光学区域之外，原面形、顶点位置和中央光学空气隙保持不变。
- 后压圈 → L7 → 2.30714mm 厚矩形隔圈 → 后胶合组 → 外围相抵环带 → 前胶合组 → 主筒前肩。

这些是新毛坯几何，不表示给已有玻璃补料，也不覆盖原 Zemax / STEP。附近镜片上的限光遮光环带以说明标注，不增加独立实体；需要后续设计不透光处理，并在 Zemax 复核 F 数、入瞳与各调焦位置通光。仅放大玻璃外径并不会自动形成原来的约Φ15限光开口。

## SolidWorks 2023

导入 `F35_Electric_v02.bas`，保存为 `.swp`，运行 `main`。生成文件在宏所在目录的新建 `Optomech_时间戳` 文件夹。新旧模块勿混在同一个宏工程中，以免 `main` 等过程重名。

生成后激活本版总装，运行 `FocusMinus2mm` / `FocusMiddle` / `FocusPlus2mm` 查看 −2 / 0 / +2mm 三个姿态。凸轮环转角为 −40 / 0 / +40°，输入小齿轮反向转5倍角度。姿态由坐标宏设置，不添加机械运动配合。此版 SolidWorks 宏尚待用户实机运行确认。

## FreeCAD 1.1.4

直接打开 `F35_Electric_v02.FCStd`；重建可运行 `F35_Electric_v02.FCMacro` 并选择输出目录。在模型树选择 `FocusControl`，修改 `AngleDeg`（−40～40°）后重算查看调焦。

固定主筒与后组固定，蓝色 L2 镜框只平移，金色凸轮环只旋转，绿色输入小齿轮在偏置轴线上反向旋转。图形显示颜色和原生可编辑特征已保存；可用裁剪视图检查内部。

## 装配顺序

1. 将前胶合组 L3/L4 从后端装入，前外围平面落在主筒肩面。
2. 装入后胶合组 L5/L6，使新增外缘环带相抵。
3. 装入厚矩形隔圈、L7，最后拧一只后压圈。后组不点胶到主筒内。
4. L2 镜框与其玻璃、前压圈预装好，再由前端装入。
5. 沿用已确认的凸轮环、止推垫片、保持环、三组销/滚子和输入齿轮装配。
6. 装入 L1 和前压圈；检查全行程和后组压紧状态。

后组均可从后端拆出；两对胶合镜片本身仍是光学胶合组，取消的是原先镜框与玻璃之间的机械点胶。

## 检查范围

24个原生实体：17个机械件＋7个玻璃参考体。实体有效、9个调焦姿态与35个装入位置检查见 `native_verification.json`。新增玻璃相抵环带已测量面积/距离，原有效光学区的处方采样值逐面核对。

后组压紧力通过玻璃外围，需进一步确定预紧力、接触平面度、倒角、定心配合与应力。机械螺纹仍为名义接口，需细化牙型与防松。调焦±2mm未标定物距；本轮未进行光线追迹、制造公差或应力认证。马达、支承/轴承、电控和相机卡口仍不在此 demo 中。
