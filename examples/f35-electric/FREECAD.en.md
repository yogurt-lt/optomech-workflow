# FreeCAD

Open FreeCAD_Model.FCStd. Each Body retains its sketches and native features. Select FocusControl, change AngleDeg within −40…+40 and recompute. L2 translates; the cam and input gear rotate. Zero is the nominal middle position.

Run FreeCAD.FCMacro through the Macro menu to regenerate into a timestamped directory. Restore component visibility, use axonometric view and Fit All; use clipping view for a section. Glass is light blue, the fixed housing teal, the moving cell blue, the cam gold and input pinion green.

See DESIGN.en.md and freecad_report.json for new glass-rim requirements, aperture scope and checks.
