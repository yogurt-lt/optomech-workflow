# Film projection · Film

User-run and reviewed in SolidWorks 2023.

L2 is the largest lens. The stack loads through one opening; the smaller L1 is first secured in an independent adapter.

## Assembly sequence

### Preassemble L1

Seat L1 in its adapter and secure it against the rear shoulder with the small retaining ring.

### Load through the main opening

L5 → spacer → L4 → spacer → L3 → spacer → L2 → L1 adapter assembly → main retaining ring.

## Location and retention

Bores center the elements. Shoulders and spacers establish axial positions at the chosen contact radii. L1 has a local clamping path inside its adapter.

## Preload path

Main ring → L1 adapter → L2 → spacer → L3 → spacer → L4 → spacer → L5 → barrel rear shoulder.

## Geometry and scope

Some contact bands intersect exported baseline ray segments. This known limitation remains in the demo. Its download contains mechanics; use the source STEP for the glass.

Optical reference blanks are sampled revolved outlines, not production optical surfaces. User confirmation covers macro execution and concept review; it does not qualify tolerances, adhesive behavior, preload or stress. Original source files remain available for comparison.
