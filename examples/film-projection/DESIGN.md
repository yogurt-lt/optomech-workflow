# 胶片投影镜头：装配方案与机械初稿 v1.0

## 输入与坐标

输入 examples/film-projection/source.STP。识别到 5 个实体，名称为 surfaces 2,3 / 4,5 / 7,8 / 9,10 / 11,12，以及光线线框。没有胶合界面；本版按 5 片独立镜片处理。长度单位 mm。各镜片局部坐标系均同轴，无旋转。

从 STEP 的有理 B 样条曲面读取母线，以端点参数截面提取光学面，并识别圆柱外缘和平面边缘台面；不把控制点包围盒当作镜片直径。平面曲面的未裁剪延伸部分不作为实体外径。原始 STEP 的首面顶点 Z=-1017.479856504 mm。说明和剖面使用首面顶点为零的局部坐标；宏输出已加回原始坐标偏置，可与原 STEP 原点对齐。

| 镜片 | 外径 mm | 前顶点局部 Z | 后顶点局部 Z |
|---|---:|---:|---:|
| L1 | 4.6314 | 0.0000 | 2.4632 |
| L2 | 6.0615 | 4.1537 | 6.8865 |
| L3 | 5.8585 | 9.5076 | 12.1003 |
| L4 | 4.6938 | 13.1038 | 14.9595 |
| L5 | 2.6481 | 16.2399 | 17.4799 |

仅凭 STEP 不能确定材料、真实倒角、公差、有效口径定义及光阑处方。没有把 surfaces 6 的缺失擅自当作光阑，也没有新增光阑。

## 装配方案

采用一只主镜筒，从 L1 一侧的最大入口单端装入。外径在 L2 处最大，随后逐级缩小；若简单套用上一套镜头的双端向内装法，大镜片会被较小定位孔挡住。

先装 L5，使后侧现有平边沉靠镜筒后肩；然后依次装入 L4-L5 隔圈、L4、L3-L4 隔圈、L3、L2-L3 隔圈、L2。L1 较小，先在独立定位套中用小压圈锁紧，再把这一组件从入口装入，最后用主压圈压紧整个堆叠。

主压紧路径：主压圈 → L1 定位套 → L2 → 隔圈 → L3 → 隔圈 → L4 → 隔圈 → L5 → 镜筒后肩。

L1 局部压紧路径：小压圈 → L1 → 定位套后肩。定位套同时承担 L1 定心、L1 后沉靠和 L1-L2 间距。它的台阶是有厚度的装配肩，没有细长压紧鼻。

镜筒外径 8.8 mm，局部 Z=-2.2～18.3 mm，总长 20.5 mm；不带对焦结构或相机/投影机安装接口。共 7 件机械零件。两个压圈暂用 M7×0.35、M5×0.35 名义接口包络，未建牙型、扳手槽与配合公差。

## 接触与加工性

有平边的位置优先用平边。曲面接触位置采用约 0.22 mm 的径向接触预留，不盲目遮入 0.3 mm。平面环件端面与曲面边缘是线接触近似，尚需真实倒角、接触角和应力校核。

三只隔圈均为四顶点截面，直外圆、渐变内孔。最薄法向壁厚保守下限分别约 0.245 / 0.204 / 0.430 mm。最小值刚超过 0.2 mm，仍应由加工方确认。镜片定位孔径向间隙按约 0.03～0.04 mm 作概念预留，非最终配合公差。

## 已执行的几何检查

- 对每个镜片，以 501 个半径、17 个厚度内点检查与各机械截面的关系，未发现实体内部交叠。
- 对机械截面的轴向顶点区间检查零件相交，未发现内部交叠；接触面允许相切。
- 按主镜筒轴向孔径检查所有插入件的最大半径包络，单端装入路径通过。
- VBA 静态检查包括 7 件轮廓、数组长度、续行限制、两处静默保存与路径核对。用户已在 SolidWorks 2023 完成建模与装配运行检查。

上述为基于 STEP 母线与采样的检查，不能代替 SolidWorks 的导入诊断和实体干涉检测。

## 已发现的通光问题

STEP 内含 1694 段位于镜组附近的导出光线。本版对每段在机械轴向范围内取 51 个点，使用真实三维半径检查，而非仅看二维投影。相交统计如下；数字是光线段数，同一条光线可跨多个段，不是光线条数或遮光百分比。

| 零件 | 检出相交的导出光线段 |
|---|---:|
| 01_MainBarrel | 0 |
| 02_L1_SeatAdapter | 4 |
| 03_L1_Retainer | 0 |
| 04_Spacer_L2_L3 | 20 |
| 05_Spacer_L3_L4 | 4 |
| 06_Spacer_L4_L5 | 2 |
| 07_MainRetainer | 0 |

主镜筒、两只压圈未检出相交；定位套及三个隔圈的曲面接触带检出相交。当前 STEP 的部分光学面已经接近导出光线边缘，不能同时直接在这些面上压住有限宽度接触带并保证全部导出光线通过。

本版是结构与装配验证初稿，不能作为已满足通光的生产设计。下一轮应提供 Zemax 处方，保留有效口径并增加真实机械外缘/平边，或确认允许的边缘遮挡后再重算沉靠与隔距；不能只把孔径继续缩小来加厚隔圈。此次没有修改原镜片 STEP。

## 在 SolidWorks 2023 中运行

导入 OptomechFilm.bas，运行 OptomechFilm.main。宏会在其保存位置旁新建 FilmProjection_时间戳文件夹，生成 7 个 SLDPRT 和 1 个 SLDASM，保留原生截面草图与旋转特征。

机械装配体暂不自动插入原光学 STEP，避免当前 STEP 导入为装配体或零件的设置差异。需要叠加观察时，将原 STEP 按原点放置，机械坐标与其一致。剖面图使用局部坐标只是为便于阅读。

成功后重点检查：L5 后平边沉靠、L1 套内后肩、两个压圈的传力路径、三只隔圈的曲面接触，以及 STEP 叠加后的轴向和径向对齐。
