# Phone lens · 6P

User-run and reviewed in SolidWorks 2023.

Choose three main bore diameters first, then extend only the required peripheral lens rims. Avoid giving every lens a large common flange or using miniature threaded retainers.

## Assembly sequence

### Load from the image side

L1 → spacer → L2 → spacer → L3 → spacer → L4 → L5 → L6.

### Secure the tail ring

Keep all contacts seated in a fixture, then locally bond the tail ring to the housing and cure it.

## Location and retention

Three simple rectangular spacers set the first gaps. Peripheral contact rims link the later lenses. Tail-ring adhesive connects the ring to the barrel rather than bonding every lens.

## Preload path

Tail ring → lens and spacer stack → front seat → barrel.

## Geometry and scope

L1/L3/L4/L5 use revised mechanical rims with the original optical bodies retained. The filter is a reserved space only. Mold release, adhesive and stress details need further design.

Optical reference blanks are sampled revolved outlines, not production optical surfaces. User confirmation covers macro execution and concept review; it does not qualify tolerances, adhesive behavior, preload or stress. Original source files remain available for comparison.
