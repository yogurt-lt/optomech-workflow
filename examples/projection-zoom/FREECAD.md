# 30–39 mm F3.5 投影变焦与整组调焦 · v0.5

三个可拆镜筒模块套在直槽内导向筒中，外层凸轮筒驱动变焦，后端短环驱动整组调焦；不用导杆。优先用简单阶梯筒、厚隔圈和端部压圈完成装配。

|机械模块|镜片与装入顺序|定位与压紧|
|---|---|---|
|G1 前组|前端：L2/L3 胶合双片 → L1 → 前压圈|L2 新制 Ø35 局部平边与 L1 原平边相抵；分段孔定心，后肩沉靠|
|G2 中组共筒|前端：L6 → 厚矩形隔圈 → L4/L5 胶合双片 → 前压圈|L6 用 Ø24.04 短孔定心、后肩沉靠；双片用 Ø30.3 孔定位；隔圈避让台阶约0.14 mm|
|G3 后组|后端：L7 → L8 → 厚斜孔隔圈 → L9 → 长隔圈 → L10 → 后压圈|L7 新制 Ø28 外围平边与 L8 相抵；阶梯孔定心，前肩沉靠；独立光阑片不承受镜片预紧|

以上是机械模块号：G2 对应原光学 G2/G3，G3 对应原光学 G4。CAD 内部零件 ID 保留。L6 定位长度约1.94 mm、名义直径间隙0.04 mm为本 demo 初值，生产配合另定。

变焦输入轮带外凸轮筒旋转0–90°，三族槽改变三个模块的位置。后端轴向固定的短调焦环旋转±45°，推动整套内筒、镜筒及变焦凸轮移动±0.6 mm；后座固定。先台面预装镜筒，再装内导向筒、凸轮和外侧肩轴/滚子，最后装后端止推与调焦部件。维修时解除电驱啮合、拆止推件和肩轴，再抽出相应模块。

内外大筒前端已缩短17.9 mm；L8–L9采用外圆定位、两端有限接触带的厚斜孔隔圈。仅L2半径增0.5、L7半径增1 mm，属于新制玻璃机械余边；源处方不变，窄边退让仍需光学确认。不新增点胶，不填充光学空气隙。

## 运行与等待

推荐下载 Projection_Zoom_v05_Fast.bas，导入 SolidWorks VBA 新宏、保存为 swp、运行 main。本版宏已由用户运行确认。大量原生凸轮切槽使 SolidWorks 宏生成较慢，请耐心等待；优化版减少中间刷新和显式重建，但没有实测提速倍数。mainReuse 可选择已有 Fast 输出并复用匹配零件；保留 .reuse 文件。基线宏 Projection_Zoom_v05.bas 也一并保留。

FreeCAD：打开 FreeCAD_Model.FCStd，修改 MotionControl.ZoomDeg / FocusDeg；或运行 FreeCAD.FCMacro。

手机端完整原生网格及边缘线加载、3D渲染预览需要时间，请耐心等待。展示保留半透明机械、清晰镜片、实体边缘线以及只看镜片/只看机械选项。

## 检查与本轮教训

57个原生有效单实体；21个同轴运动包络、662个装入位置采样通过。逐片检查径向定位孔段，并记录各组沉靠与压紧路径。旧版L6仅轴向夹紧却放在大孔中，本版补齐小孔定位；无干涉和可装入不能代替完整装配检查。

先合并恒定间隔的同步组，再逐片恢复阶梯孔定位；近间距先比较局部平边相抵或可拆胶接镜框，避免微小隔圈。隔圈须有定心、有限接触带及足够截面，不能先顶到无关金属台阶。光阑采用独立黑化圆环片，避免尖刺并与镜片预紧分开。缩短套筒需复查全行程导向、槽端余料和出光包络。详见 Skill 的 assembly-completeness 与 compact-sleeves。

通光、接触应力、预紧、公差及完整三维凸轮接触仍需后续校核；源焦距仅30/34.5/39 mm三档，中间为机械插值。
