# v0.5：补齐 L6 径向定位

旧版 L6 外径 Ø24，所在孔 Ø30.3，虽然有后肩和隔圈轴向夹紧，但缺少径向定心。本版在同一 G2 镜筒增加 Ø24.04 小孔定位段；镜片外圆有效定位长度约1.940 mm。名义直径间隙0.04 mm仅为 demo 初值，生产配合另定。

前端装入顺序：L6 → 厚隔圈14 → L4/L5 胶合双片 → 前压圈11。
压紧路径：前压圈 → 双片 → 隔圈 → L6 → 镜筒后肩。
隔圈后端距新增孔台阶约0.140 mm，避免先顶住金属而不能压紧玻璃。

机械模块统一命名：G1 前组（L1–L3）、G2 中组（L4–L6）、G3 后组（L7–L10，含独立光阑片）。G2 对应原光学 G2/G3；G3 对应原光学 G4。光学处方组号与机械模块号分开使用。CAD 内部零件 ID 保留，以免破坏引用及缓存。

保留 v0.4 的 L8–L9 厚斜孔隔圈、大镜筒前端缩短、独立黑色光阑片和三只共运动镜筒方案。原始光学文件不变。

## 文件与运行

- Projection_Zoom_v05.FCStd：原生可编辑 FreeCAD 模型，保留前版视图与颜色。
- Projection_Zoom_v05_Fast.bas：优化 SolidWorks 宏，首次运行 main；mainDiagnostic 逐次检查；mainReuse 选择此前 Fast 宏输出目录进行匹配复用。
- Projection_Zoom_v05.bas：保留完整检查频率的基线宏。
- Projection_Zoom_v05.FCMacro：从参数重新生成 FreeCAD 模型。
- Projection_Assembly.png：与本版宏同源的装配剖面。
- support_audit.json：逐片径向定位检查和各组轴向传力记录。

若已有 v0.4 Fast 成功生成的输出，mainReuse 可匹配复用未变零件；保留 SLDPRT 旁的 .reuse 文件。没有有效匹配就重新生成，原输出不修改。

## 验证范围

57 个原生 Body 均为有效单实体；21 个变焦/调焦位置的同轴包络和662个装入采样位置未检出重叠。10片镜片逐片找到名义径向定位孔段；旧版 L6 失败、新版通过的对照已记录。各组沉靠/压紧路径为明确的工程审查记录，未声称完成自动接触应力验证。

SolidWorks 两个新宏已做静态检查，尚待本机实际编译运行；优化版未实测提速倍数。完整三维凸轮接触、通光、公差、预紧力及新增玻璃余边仍需后续校核。本次只交付本地修订，未更新线上案例。
