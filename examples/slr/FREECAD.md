# 单反三段外筒 v5：FreeCAD v0.2

打开 `FreeCAD_Model.FCStd`，或在 FreeCAD“宏 → 宏”中运行 `FreeCAD.FCMacro`，选择输出目录。生成新的原生文档，原 Zemax、STEP 和旧 SolidWorks 文件不覆盖。

## 采用的方案

使用用户最终确认的加厚 v5，保留三个外筒的连续连接根部和渐变外轮廓，不使用曾出现薄桥的 v4。13 个机械 Body、11 个采样玻璃参考 Body；十个光学组中 G8 是两片胶合组，所以玻璃实体多一个。

机械截面顶点、玻璃采样轮廓、源 Z 偏置与已接受的 SolidWorks v5 保持一致。前/中/后外筒分别蓝、青、棕；三个内部镜框统一灰色；隔圈绿、压圈深灰、玻璃半透明蓝。光阑与中筒一体、同为青色。

## 附加特征

原生草图＋Pocket 生成 15 个径向孔：

- 前筒 Z70 的三个 Ø4.5 M4 通孔。
- 中筒 Z70、Z134 的六个 Ø3.3 M4 攻丝底孔。
- 后筒 Z134 的三个 Ø4.5 M4 通孔。
- G8 薄框 Z185 的三个 Ø3 点胶入口。

上述 Z 均为方案局部坐标；孔位角向明确为 90°/210°/330°，成对的筒连接孔同轴。原坐标输出统一加回 -386.074 mm。

三个压圈各两个相对扳手槽，共六槽。切向宽 4 mm、径向切入 4 mm、轴向切深 3 mm，压圈总厚 6 mm。每个槽组保留独立 Sketch 和 Pocket，可编辑。

螺纹仅用名义包络表示，不生成牙型或六颗连接螺钉实体。中筒 A/B 框仍在台面从暴露的框口局部点胶，只有 G8 薄框原方案指定点胶孔。未增加或遗漏胶入口。

## 装配顺序

- 前筒从物侧 −Z 装：G2 → 前锥隔圈 → G1 → 前压圈。
- A 框在台面从前侧装 G4、G3，分别沉靠、定心并局部胶接。
- B 框在台面从前侧装 G5、从后侧装 G6，分别沉靠、定心并局部胶接。
- G8 胶合组从薄框后侧装入，沉靠、定心并局部胶接。
- 中筒从前端装完整 B 框 → 完整 A 框 → 总压圈；压紧走金属框端面，不压光阑孔口。
- 后筒从像侧 +Z 装：G7 → 长隔圈 → G8 薄框组件 → 短隔圈 → G9 → 杯形隔圈 → G10 → 后压圈。
- 完成各筒内部装配后，将中筒前止口插入前筒承孔，再将后筒承孔套到中筒后止口，锁紧径向螺钉。

前、中、后三段的实际装入方向不同。相邻框中的凸出玻璃需要在另一框的孔内让位，不能把框端面误认为玻璃顶点。

## 光阑与结构

中筒一体光阑名义孔 Ø87.2 mm；入口斜面与轴线成 60°，平口从局部 Z140.16 到 Z141.66，长 1.5 mm。与原 v5 保持一致。未重新追迹通光。

加厚 v5 未开孔旋转主体的最小内外轮廓距离，原方案检查约为前筒 8.98、中筒 8.10、后筒 8.47 mm。数值不能当作开孔后应力或连接强度认证。

## 验证与检查

实际 FreeCAD 运行结果在 `freecad_report.json`：24 个单实体 Body、保存重开、机械原生布尔干涉、孔位同轴/单侧切穿、扳手槽深度；并分别检查台面预装、各筒装入与两处整筒套合的轴向路径。平移路径采用采样，不模拟牙型、螺钉拧紧、胶接或实际扳手；玻璃接触体积单独记录，不能代替精确光学面。

模型树里隐藏三个外筒可查看内部；恢复后用 X=0 剖切，重点看两处加厚接头、青色光阑平台及 G8 灰色薄框。完整宏已包含玻璃，不要再叠加原 STEP。

所有组件按共同坐标摆放，不创建 Assembly 工作台关节。生产导向配合、螺距/牙底、公差、接触、预紧、胶接和热应力需要另行工程细化。若宏报错，提供输出目录的 `build_report.json`。
