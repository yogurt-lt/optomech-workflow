# 变焦机械v0.2：修改与装配

## 修改结果

G3原1mm环形薄连接被取消。L8增加机械余边至Ø64，原光学面保留到原机械半径22.138；新前余边过渡至Z222.5平面（r≥28），新后余边沿原外缘后面Z231.820736延续。余边用于定位与承压，不作为光学面。

G3镜片座前段外径Ø69、定位孔Ø64.3，主壁2.35mm；沉靠局部厚1.5mm。外支撑环外半径45、后孔半径37，径向壁8mm。外支撑从Z226.43开始，玻璃后端承压面Z231.820736，连接处最小轴向实体长度5.390736mm。31后压圈厚3mm、径向宽6.3mm（r30.5～36.8），筒体在全长支承其名义螺纹。

G4取消L9独立镜框40。主筒42为一体光阑筒：L9前装、L10后装。L9前压圈41厚3mm、径向宽2.9mm，前颈外半径29.8、螺纹孔半径27.45，壁厚2.35mm；随后过渡到主筒半径35.5。长焦端G3后压圈内孔半径30.5与G4前颈29.8径向错开0.70mm；G3后袖与G4主筒径向错开1.50mm。光阑仍为Ø41.602、轴向1.6mm平台，两侧斜面。

先尝试过G3前压圈，但在中间变焦位置与L7相撞；已撤销该中间版本。交付方案恢复G3后装，并利用新增机械余边获得宽厚承力空间。

## 光学装配与点胶

1. G1前端单向：L4 → 隔圈05 → L3 → 隔圈04 → L2 → 隔圈03 → L1 → 前压圈02。三只矩形隔圈保持上一版。
2. G2台面预装：L5后装靠前肩 → 压圈21；L6/L7原胶合双片装短框22，靠后肩、治具找正、三点局部施胶、固化复查；框法兰靠21金属面 → 压圈23。完整光学短筒25装入滑架20，以止口/后肩定位及三个锁钉保持。
3. G3：L8从后端装入靠前余边平面 → 后压圈31。镜片与G3不新增点胶。
4. G4台面预装：L9从前端靠光阑前侧后肩 → 前压圈41；L10从后端靠光阑后侧前肩 → 后压圈43。两片各自独立锁紧，再将主筒整体装到后固定座。前压圈在台面操作，不在狭窄变焦间隙内拧紧。
5. 后尾芯44：L11 → 矩形隔圈45 → L12 → L13 → 后压圈46。L12/L13沿上一版Ø38新机械外缘相抵；尾芯最后定位并用螺钉安装。

新增点胶仅在L6/L7双片外圆与短框22之间，三处Ø3通道位于30°/150°/270°。不重新胶合L6/L7光学界面；胶不跨接L5与双片的狭小间隙，压紧力经金属法兰传递。胶量、胶层、材料及固化参数尚待指定。

## 变焦和维修

20齿输入轮驱动128齿凸轮筒，模数1.25、压力角20°、中心距92.5。凸轮筒轴向固定，转角0～330°；每组一条曲线槽、一个滚子，G2沿X方位的一对导杆、G3沿Y方位的一对导杆平移。导杆承重及止转，凸轮负责驱动；输入轮角为凸轮角的−6.4倍。G2向像方行程111.568mm；G3先前移7.715mm，终点相对起点后移19.908mm。五个源组态间为机械插值，尚未逐位置重新验证成像。

骨架先装导杆/滑架、支撑柱，后座及滚子未装时套凸轮，再装后座与止推件；从外侧装滚子肩轴，装输入齿轮；随后装预装光学模块及上下盖。终点冲击由独立止挡承担。

G2维修：凸轮0°服务位，支撑并拆G1，退开光学短筒三锁钉，从前抽出短筒，导杆/滑架保留。G3维修：先拆完整G4，从后接近压圈31并取出L8；完整G4在长焦端退出的抽样路径另作检查。G4尾芯可单独后拆。外盖沿±Y分开，端部开口槽绕过支撑柱及止挡销。

原STEP对应源组态1，ZMX基础DISZ对应组态5。本版基准仍为组态1，G4的源累计舍入差0.002mm沿用显式归一处理。参考镜片为处方抽样回转体，原STEP某些边缘采样与名义圆有差异，不能将参考体视为精确复刻。生产配合、预紧、消隙、应力与热漂移待细化。

## v0.2检查

五个修改Body（含L8参考体）在原生构建时检查有效性。91个Body重新打开后检查单一实体及构建体积一致；修改件与总装其余件在9个角度复查穿插；未修改件之间沿用v0.1通过的检查，记录附在baseline_v01_verification.json。重新检查了155个装入及拆出位置，未检出大于0.001mm³的穿插。检查为名义抽样，SolidWorks 2023 宏已由用户运行检查；其中长凸轮切槽与近重合截面点问题已修复。原生抽样报告记录 FreeCAD 检查范围，不替代 SolidWorks 内核校核。
