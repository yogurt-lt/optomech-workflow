# Seven-times zoom objective

Source configuration labels: 24.42–187.67 mm (ratio7.685, approximately7.7x). G1/G4 fixed, G2 variator, G3 compensator. An axially fixed cam with128 teeth is driven by a20-tooth input; independent guide rods carry the sliding groups. Cam travel0–330 degrees. The web preview uses full native CAD meshes, with illustrative transparent housing; no cutting plane.

L8 requires a newly manufactured OD64 mechanical rim, preserving its original optical zone. L9 and L10 load from opposite ends of an integral stop body. One locally bonded doublet cell remains in G2. Four rectangular optical spacers. See the annotated section for installation order. Intermediate motion is mechanically interpolated from five source configurations, not recalculated optical performance.

FreeCAD: open FreeCAD_Model.FCStd and edit ZoomControl.AngleDeg. SolidWorks2023: import Zoom_v02.bas, run main; it saves/closes each part to limit document-window use. The portable macro starts a fresh build; it contains no workstation-specific resume paths. Short cam cuts are compatible with the tested recovery method but can take time. ZoomPosition1–5 switches assembly positions.
